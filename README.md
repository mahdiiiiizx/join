# ربات جوین اجباری تلگرام

## نصب

```bash
pip install -r requirements.txt
```

## تنظیم اولیه

1. فایل `bot.py` را باز کنید و مقادیر زیر را وارد کنید:
   - `BOT_TOKEN` → توکن ربات از @BotFather
   - `OWNER_ID` → آیدی عددی خودتان (از @userinfobot بگیرید)
2. ربات را اجرا کنید:
   ```bash
   python bot.py
   ```
3. ربات را در گروه مورد نظر **ادمین** کنید (با دسترسی حذف پیام).
4. ربات را در کانال‌های جوین اجباری هم **ادمین** کنید (با دسترسی ساخت لینک دعوت در صورت نیاز).
5. در پیوی ربات دستور `/start` را بزنید تا پنل مدیریت باز شود.
6. از پنل: «تنظیم گروه» → یک پیام از گروه فوروارد کنید یا آیدی عددی گروه را بفرستید.
7. از پنل: «مدیریت کانال‌ها» → «افزودن کانال» → یک پیام از کانال فوروارد کنید، یا دستی به فرمت زیر بفرستید:
   ```
   @channel_username | https://t.me/channel_username
   ```

## ویرایش متن‌ها

از پنل مدیریت → «ویرایش متن‌ها» → متن هشدار یا متن تایید عضویت را ویرایش کنید.

متغیرهای قابل استفاده در متن‌ها:
- `{mention}`
- `منشن_کاربر`

هرکدام را در متن بگذارید، جای منشن کاربر قرار می‌گیرد. اگر هیچ‌کدام را نگذارید، منشن به‌صورت خودکار در ابتدای پیام اضافه می‌شود (چون تگ کردن کاربر الزامی است).

## نکته درباره رنگ دکمه‌ها

قابلیت رنگی‌کردن دکمه‌های شیشه‌ای (inline keyboard) از سمت کد ربات در API رسمی تلگرام برای بات‌ها وجود ندارد؛ این ویژگی صرفاً از سمت کلاینت/کاربر برای شخصی‌سازی ظاهریست و پارامتری در سطح Bot API برایش تعریف نشده، پس در کد قابل تحمیل نیست.

## محدودیت‌های اعمال‌شده طبق درخواست

- ربات فقط در یک گروه (تعیین‌شده توسط مالک) فعال است.
- فقط مالک (`OWNER_ID`) به پنل مدیریت در پیوی دسترسی دارد.
- کانال‌ها قابل افزودن/حذف هستند.
- منشن کاربر در تمام پیام‌های هشدار/تایید اجباری و تضمین‌شده است.
- پیام کاربر غیرعضو حذف و پیام هشدار جایگزین می‌شود؛ با تایید عضویت، همان پیام ادیت می‌شود.

## آیتم نوع «ربات» (بدون نیاز به دیتابیس مشترک)

از پنل: «مدیریت آیتم‌ها» → «افزودن ربات» → یوزرنیم (`@id_bot`)، لینک (`https://t.me/id_bot`) یا لینک با پارامتر (`https://t.me/id_bot?start=ref123`) را بفرستید.

- دکمه‌ی ربات در پیام جوین اجباری یک دکمه‌ی callback است.
- کاربر که روی آن بزند، همان لحظه عضویتش در آن ربات ثبت (تایید) می‌شود و پیوی ربات مقصد با لینک استارت برایش باز می‌شود؛ فقط باید Start را بزند.
- نیازی به تغییر در ربات مقصد نیست.
- محدودیت: چون تلگرام راهی برای فهمیدن «Start واقعی» در ربات دیگر نمی‌دهد، تایید بر پایه‌ی کلیک است.
- در مدیریت هر ربات، دکمه‌ی «کاربران عضو شده» تعداد کلیک‌ها را نشان می‌دهد.

## رفتار پیام هشدار

- فقط مواردی که کاربر هنوز در آن‌ها عضو نیست نمایش داده می‌شود. با زدن «بررسی عضویت»، دکمه و اسم مواردی که عضو شده حذف می‌شود و بقیه می‌ماند.
- لیست موارد باقی‌مانده داخل نقل قول (blockquote) چاپ می‌شود.
- متن‌های پیش‌فرض بولد هستند.
- متن‌هایی که مالک در پیوی تنظیم می‌کند با تمام قالب‌بندی (بولد، کج، نقل قول، زیرخط، اسپویلر، اموجی پریمیوم و...) ذخیره و همان‌طور ارسال می‌شود. متن را در تلگرام قالب‌بندی کنید و بفرستید.
- اگر متن قدیمی‌ای که قبل از این نسخه ذخیره شده بود کاراکتر `<` یا `&` داشت و ارسال نشد، ربات خودکار متن پیش‌فرض را می‌فرستد؛ متن را دوباره تنظیم کنید.

## نحوه‌ی کار دکمه‌ی ربات

دکمه‌ی هر ربات یک لینک به آدرس خودِ همین سرویس است (`/go/...`)؛ با کلیک، عضویت کاربر ثبت می‌شود و بلافاصله به پیوی ربات مقصد هدایت می‌شود.
- متغیر `WEBHOOK_SECRET` را در Render **ثابت** ست کنید، وگرنه با هر ریستارت لینک‌های پیام‌های قبلی نامعتبر می‌شوند.
- `RENDER_EXTERNAL_URL` یا `WEBHOOK_URL` باید آدرس عمومی https سرویس باشد.
